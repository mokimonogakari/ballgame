# ぽよんぽよんボール

ボールが自動でぽよんと跳ねます。左右に動かしてゼリーの床を登り、★を集めるゲームです。

## あそびかた
- スマホ: 画面のどこでも指を置くと、ボールが指の横位置へついてくる（PCは ← →）
- ちょんと短くタッチ（2本目の指・PCはスペース）で、着地までに1回だけ「もういちど ぽよん」
- ★ = 5点。続けて取るとコンボで最大25点
- とげとげは上から踏むと +15点。横から当たるとハートが減る
- ハートは3つ。落ちても助けの床で復活

## しかけ
- 床: ゼリー / びよーん（大ジャンプ） / うごく床 / クッキー（1回で割れる）
- アイテム: 🚀ロケット（上まで飛ぶ・無敵） / 🧲じしゃく（★を吸い寄せる） / 💖ハート
- ステージ: そら → ゆうやけ(500m) → よぞら(1200m) → うちゅう(2000m) → ほしのくに(3000m)
- タイトルでボールの色を選べる。さいこう記録を保存

GitHub Pages で `index.html` をそのまま公開できます。
